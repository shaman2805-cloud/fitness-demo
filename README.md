# Fitness Club Demo

Демонстрационный мобильный прототип фитнес-приложения.

## Как запустить

Вариант 1:
Просто откройте `index.html` двойным нажатием.

Вариант 2 — через локальный сервер:
```bash
cd fitness_demo
python3 -m http.server 8000
```

После этого откройте:
http://localhost:8000

## Уже работает
- Главная
- Просмотр активного абонемента
- Запись/отмена записи на тренировку
- Расписание
- Тренеры
- Прогресс
- Профиль
- Мобильная нижняя навигация

Данные пока демонстрационные. Следующим этапом можно подключить реальную базу данных, авторизацию, покупки абонементов, магазин, уведомления и админ-панель.
